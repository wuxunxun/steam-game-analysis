# Steam Game Analysis

Python final project for **CP388001**, exploring Steam game attributes and popularity through data preparation, aggregation, and visualization.

**Author:** XUN WU — 695380025-4

## Project files

- [Main notebook](code/final_run.ipynb): step-by-step analysis, explanations, and commented code.
- [Data](data/): local source and prepared datasets; excluded from Git.
- [Documents](docs/): research paper, references, and final report materials.
- [Resources](resources/): exported images and charts.
- [Requirements](requirements.txt): Python dependencies.

## Run

Open the project folder in VS Code and select its `.venv` as the notebook kernel. Install dependencies if needed:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Run `code/final_run.ipynb` in cell order. Data acquisition and analysis are being developed step by step.
